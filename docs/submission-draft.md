# momentas

**Tagline:** Let me show you how I remember it.

**Primary track:** Meta — Bringing People Closer Together with AI.

**Live app:** https://momentas-hacktx.vercel.app

**Source:** https://github.com/ramikamel/momentas (private)

momentas helps parents, children and friends share a memory as they experienced it. A storyteller describes an event, reviews AI-extracted details and shapes a photorealistic AI reconstruction until it reflects their perspective. They share the approved image with someone who can ask questions and receive replies from the actual storyteller.

The image makes a concrete starting point for questions about details, feelings and experiences ordinary updates can miss. The central outcome is a human exchange: seeing a moment through someone else's eyes and asking them about it.

Muse Spark creates an editable scene with verbatim source quotes. Muse Image generates the image and refines selected versions using earlier image as a reference. The storyteller reviews the interpretation and controls publication. Human replies are never generated by AI.

Built with Next.js, React, TypeScript, Tailwind, Supabase Postgres/private Storage, Muse Spark and Muse Image. Codex assisted implementation, testing and review. State the actual coding model/harness in the final form if requested. Voice capture and editable transcription use Muse Voice Transcribe.

Demonstrated scope: recorded or written memories, image refinement and retained versions, selected quote pins, unlisted sharing, independent second perspectives, an evidence-linked comparison reveal, and contextual questions with human replies. The presenter can play both sample roles in separate browsers. Generated image represents a subjective interpretation; the sample is fictional and labeled.

The connection extension uses immutable publication snapshots so the two people deliberately choose which image, caption, pin excerpts and optional narration are shared. Muse Spark compares only those approved public captions/excerpts and returns attributable quotations, without deciding whose recollection is correct. Both scenes remain available if insight generation fails. The demo can be performed alone in two labeled fictional roles and separate browser contexts.
