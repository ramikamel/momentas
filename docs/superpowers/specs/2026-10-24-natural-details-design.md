# Natural image details

User-requested design: after generation, show **Add a detail** directly on the image editor. The author clicks/taps the image, writes a new note, and saves it. Remove the annotation disclosure, predetermined scene dropdown, quote-copying requirement and separate save-all action. Existing sourced pins and published snapshots remain compatible.

Approaches: keep quote selection (rejected: contradicts the requested flow); free notes with point markers (reliable baseline); free notes with optional SAM object outlines (chosen implementation proposal: same interaction plus meaningful Meta integration). The configured key lists sam-3.1. Attempt a real point-prompt mask as the author types; a failed or unsuitable outline never prevents saving a point note. The author can discard the outline. No invented outlines or generated note text.

Free notes are attributed as author additions, not original transcript quotes. Bound notes to 500 characters, five per version, normalized positions, and bounded validated outline geometry. Persist in existing private JSON pin records with server validation and ownership checks; preserve legacy source validation. All publication, recipient question and comparison paths retain notes/geometry and frozen snapshots. A small additive 003 migration persists paid outline reservations; no credential changes. Keyboard users can place with arrows/Enter and adjust positions; cancel discards only unsaved work. Saving/removing is explicit and atomic with recoverable errors.

SAM requests use only the owner's saved image, server-held API key, a single positive point and bounded output/time limits. Reject foreign image versions and arbitrary URLs. Dedicated atomic paid request reservations bound attempts to 20 per image version and 120 across the project, including failed calls; one pending call per version expires after 120 seconds. No hidden retries. Actual object selection can be imperfect: keep a visible simple-pin fallback and let users choose a different spot.

Ruling: the user specified the authoring interaction directly, so implementation followed that request without another UI approval round. Outlines use the existing Meta key and optional fallback, as described in commentary. Native worktree tooling remains tied to the stale untitled chat folder; the previously verified manual worktree fallback was used. Review found process-local rate limits insufficient; replaced them with the additive 003 migration before release.
