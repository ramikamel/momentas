# Outside-the-frame focus

User request: make homepage entry choices clear and equally formatted; prioritize the outside-frame recollection and reveal in photo mode, rather than the object-story tools.

Implementation: one editorial introduction followed by matching photograph/words cards. The words form opens on explicit choice/sample. Each path creates its own draft. Photo mode opens with the original and recollection prompt together; generation replaces the prompt panel with the wider reconstruction. Editing restores the prompt; sharing remains explicit. Original pixels, provider prompts, storage and permissions are unchanged. Optional detail stories are below a deliberate action and are not mounted or analyzed until requested; existing notes and recording recovery remain available there.

Alternatives considered: merely moving the old upload block would leave competing page hierarchy; moving only the prompt above the old annotation workspace would still make two experiences compete. The chosen layout follows the user's explicit outside-frame emphasis while retaining existing detail stories as an optional tool. No schema changes or new dependencies.

Validation: entry choice, prompt placement, no background object requests before optional details, responsive layout, existing story/voice/share journeys and production build.
